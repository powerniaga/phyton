📖 Nota Pembelajaran Interaktif

Pelajari konsep asas Python secara langkah demi langkah.

Nota 1

Apa Itu Python?

Python ialah bahasa pengaturcaraan (programming language) yang sangat popular, mudah dibaca, dan digunakan untuk memberi arahan terus kepada komputer.

Contoh Kod Python: main.py
print("Hello World")
Klik button di sebelah untuk melihat output.
Fungsi print() digunakan untuk memaparkan teks atau nilai pada skrin komputer.
Nota 2

Konsep Variable (Pembolehubah)

Analogi Mudah:
Bayangkan Variable seperti sebuah KOTAK yang ditampal label. Kotak ini digunakan untuk menyimpan maklumat di dalam memori komputer supaya boleh digunakan semula nanti.

Contoh Variable & Nilai Dalam Python:

nama = "Amirul"
umur = 21
cgpa = 3.68
Variable (Nama Label Kotak) Nilai (Kandungan Dalam Kotak)
nama"Amirul"
umur21
cgpa3.68

Memaparkan Isi Variable:

print(nama)
print(umur)
print(cgpa)

Cara Menamakan Variable

BETUL ✅
  • nama = "Ali"
  • umur = 21
  • harga_servis = 150
  • nombor_plat = "VAB1234"

Gunakan huruf, nombor di belakang, atau underscore (_).

SALAH ❌
  • 2nama = "Ali" (Bermula nombor)
  • harga servis = 150 (Ada jarak/space)

Dilarang mulakan dengan nombor atau mengandungi ruang jarak.

Nota 3

Menerima Input Pengguna

Fungsi input() digunakan untuk meminta dan menerima maklumat terus daripada pengguna semasa program dijalankan.

nama = input("Masukkan nama anda: ")

🚘 Tugasan Hari Ini — Program Rekod Kenderaan

Bina program Python yang meminta 5 maklumat kenderaan dan memaparkannya semula.

Maklumat Yang Perlu Diminta Dari Pengguna:

  • 1. Nama Pemilik
  • 2. Model Kereta
  • 3. Nombor Plat
  • 4. Tahun Kereta
  • 5. Mileage (KM)
TARGET OUTPUT SAMBILAN:
========== REKOD KENDERAAN ==========
Pemilik: Ahmad
Model: Honda City
No. Plat: VAB1234
Tahun: 2022
Mileage: 45000 KM
======================================
Tahap Bantuan / Hint Pembelajaran:
Hint 1: Gunakan fungsi input() untuk meminta setiap maklumat.
Hint 2: Simpan setiap maklumat input dalam variable tersendiri seperti pemilik = input(...).
Hint 3: Gunakan fungsi print() untuk memaparkan semula maklumat dalam format rapi.
CONTOH KOD JAWAPAN LENGKAP:
pemilik = input("Nama pemilik: ")
model = input("Model kereta: ")
plat = input("Nombor plat: ")
tahun = input("Tahun kereta: ")
mileage = input("Mileage: ")

print("========== REKOD KENDERAAN ==========")
print("Pemilik:", pemilik)
print("Model:", model)
print("No. Plat:", plat)
print("Tahun:", tahun)
print("Mileage:", mileage, "KM")
print("======================================")
